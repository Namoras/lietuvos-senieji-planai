# Vilniaus senieji planai ir archeologiniai radiniai

Interaktyvus žemėlapis: dabartinis Vilnius su senaisiais planais (Brauno ir Hogenbergo 1581 m. plano patikimi gabalai, 1842 m. ir 1916 m. planai) ir archeologinių radinių taškais.

- **Metų slankiklis:** rodo naujausią planą iki pasirinktų metų ir radinius, kurių laikotarpis apima tuos metus.
- **Transparency:** senojo plano permatomumas.
- **Google Maps:** įrašykite savo Google Maps JavaScript API raktą į `config.js` (apribokite jį šios svetainės adresu). Be rakto naudojamas Esri palydovas ir OpenStreetMap.
- **QGIS:** `Braun_Vilnius_1581_LKS94.tif` (EPSG:3346).

Senieji planai: Wikimedia Commons (vieša nuosavybė). Nuotraukų autoriai ir licencijos nurodyti radinių kortelėse.
